# SmartLearning - Online Education Platform

A comprehensive MERN stack educational platform for 5 American students with features:
- Video/Audio Calls
- Resource Uploading
- Online Tests
- Educational Games
- And more

## Tech Stack
- **M**ongoDB - Database
- **E**xpress.js - Backend Framework
- **R**eact.js - Frontend Library
- **N**ode.js - Runtime Environment

## Additional Technologies
- Socket.io - Real-time communication
- WebRTC - Video/Audio calls
- JWT - Authentication
- Multer - File uploads
- Bootstrap/Material-UI - Styling
